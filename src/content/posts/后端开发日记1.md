开始接触后端以后，第一件事不是立刻写接口，而是先弄清一次请求会经过哪些模块。这个项目从通用能力、权限框架到无人机配送业务都放在同一个 Maven 聚合工程里，如果没有先确定边界，很容易把业务代码写进入口模块，或者让 Controller 承担过多职责。

## 1. 工程模块怎么分

父工程统一管理 Java 17、Spring Boot、MyBatis、PageHelper 等依赖版本，实际代码按职责拆分：

| 模块 | 职责 |
| --- | --- |
| `uav-admin` | Web 服务启动入口与系统级 Controller |
| `uav-common` | 返回结构、分页、异常、工具类等通用能力 |
| `uav-framework` | Spring Security、Token、Redis 与系统配置 |
| `uav-system` | 用户、角色、菜单、字典等后台基础功能 |
| `uav-quartz` | 定时任务调度 |
| `uav-generator` | 数据表代码生成 |
| `uav-manage` | 订单、异常、飞行、用户、报表等配送业务 |

`uav-admin` 依赖其他模块并负责启动，但真正的配送逻辑集中在 `uav-manage`。这样既能复用后台框架，也不会让业务代码和系统管理代码互相缠绕。

## 2. 一次请求的调用链

业务接口基本遵循四层结构：

```text
HTTP 请求
  -> Controller：接收参数、鉴权、分页、组装响应
  -> Service：校验业务条件、控制事务、组织多表操作
  -> Mapper：声明数据访问方法
  -> Mapper XML：编写 SQL 与结果映射
```

例如用户查询异常反馈列表时，Controller 只负责开启分页并返回统一表格结构：

```java
@GetMapping("/list")
public TableDataInfo list(HyExceptionTicket query) {
    startPage();
    List<HyExceptionTicket> rows = service.selectUserExceptionTicketList(query);
    return getDataTable(rows);
}
```

当前用户是谁、允许查询哪些数据，则由 Service 根据安全上下文补充，不能相信前端传来的用户 ID。

## 3. 两类接口边界

同一张业务表会同时服务管理端和小程序，但两端权限完全不同。项目在 Controller 层直接区分：

- `controller/admin` 面向后台人员，配合 `@PreAuthorize` 做菜单权限校验；
- `controller/user` 面向当前微信用户，只允许访问自己的订单、地址、凭证和消息；
- 通用业务规则继续复用同一个 Service，避免两套状态逻辑逐渐不一致。

这种拆分比在一个接口里判断“来源是后台还是小程序”更清楚。接口路径本身就表达调用方，审查权限时也更容易发现遗漏。

## 4. 统一返回与分页

普通接口使用 `AjaxResult`，列表接口使用 `TableDataInfo`。`BaseController` 已经封装了常见处理：

```java
startPage();          // 从请求参数读取 pageNum、pageSize
getDataTable(list);   // 返回 rows、total、code、msg
toAjax(rows);         // 根据受影响行数返回成功或失败
success(data);        // 返回业务数据
```

分页必须在 Mapper 查询之前开启，因为 PageHelper 依赖当前线程中的分页参数。把 `startPage()` 放到查询之后，返回结构看起来仍然正确，实际却会一次读取全部数据。

## 5. DTO、实体和 VO 不混用

项目里三类对象承担不同任务：

- DTO 接收某个动作需要的参数，例如下单、审核、异常处置；
- Entity 对应数据库记录，供 Mapper 读写；
- VO 控制返回给前端的字段，例如只返回 `hasImage`，不暴露磁盘路径。

不是每个简单 CRUD 都必须建立三套对象，但涉及身份、文件路径或后台字段时，直接返回实体会扩大接口暴露面。后续的用户资料、配送凭证和报表接口都采用了这种隔离。

## 6. 本篇小结

多模块并不是为了把目录变多，而是先划清稳定能力和业务能力的边界。Controller 保持薄、Service 承担业务、Mapper 专注数据访问，再配合统一响应和端侧隔离，后面的订单状态、异常处置与第三方平台接入才有清晰的落点。
